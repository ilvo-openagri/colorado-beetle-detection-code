# Data preparation

In de map `data` moeten 2 mappen zitten:

 - `images_full`: hierin zitten de afbeeldingen van 5000x8000px
 - `labels_full_txt`: hierin zitten de labels in .txt bestanden

Het bestand `image_preparation.ipynb` maakt alle mappen aan om de modellen te trainen en vult ze met trainingsdata.
